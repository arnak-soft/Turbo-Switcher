# Turbo Switcher

Бесплатный и открытый аналог Punto Switcher для Windows. Автоматически исправляет текст, набранный не в той раскладке.

Набрали `ghbdtn` — программа сама заменит на `привет` и переключит раскладку. Работает и в обратную сторону: `руддщ` → `hello`.

## Установка

Скачайте один из файлов со страницы [Releases](../../releases):

| Файл | Что это |
|---|---|
| **TurboSwitcher Setup X.X.X.exe** | Установщик — можно выбрать папку и включить автозапуск |
| **TurboSwitcher X.X.X.exe** | Portable-версия — просто запустите, установка не нужна |
| **TurboSwitcher X.X.X-net8.exe** | Маленькая версия — нужен [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) |

После запуска программа появится в системном трее (область уведомлений возле часов).

## Возможности

- **Автоисправление** — набранное не в той раскладке слово исправляется автоматически после пробела или Enter
- **Горячая клавиша** — быстро включить или выключить автоисправление (по умолчанию `Scroll Lock`, можно изменить в настройках)
- **Pause** — исправить последнее набранное слово вручную
- **Shift + Pause** — исправить выделенный текст
- **Иконка в трее** — быстрый доступ к настройкам, приостановка работы
- **Автозагрузка** — может запускаться вместе с Windows (включается в настройках)
- **Слова-исключения** — слова, которые не нужно исправлять (например, `lol`, `github`)
- **Игнор программ** — можно отключить автоисправление для отдельных приложений
- **Caps Lock** — при включённом Caps Lock автозамена не работает

## Настройки

Откройте окно настроек двойным кликом по иконке в трее. Файл конфигурации хранится в папке `%APPDATA%\Turbo Switcher\config.json`.

## Для разработчиков

.NET 8. Нужен [SDK .NET 8](https://dotnet.microsoft.com/download/dotnet/8.0).

### Сборка

```bat
publish.bat
```

Версия берётся из последнего git-тега вида `v*.*.*`. Без тега собирается как `0.0.0-dev`.

Готовые файлы появятся в папке `publish\`. Для сборки установщика нужен [Inno Setup 6](https://jrsoftware.org/isdl.php).

### Запуск из исходников

```bat
dotnet run --project src\TypoSwitch\TypoSwitch.csproj
```

### Тесты

```bat
dotnet test
```

### Выпуск новой версии

```bat
git tag v1.2.0
publish.bat
```
